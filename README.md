# Windows XT browser workshop

[Open the published workshop](https://astrobleem.github.io/mygithubpage/windows-xt/).

Try Windows XT and build a DOS program in two separate browser workspaces.
The app, original tooling, GPL runtime sources and host tests are on the
[gh-pages source branch](https://github.com/astrobleem/mygithubpage/tree/gh-pages).

See [Claude instructions](https://github.com/astrobleem/mygithubpage/blob/gh-pages/CLAUDE.md)
and [private workspace instructions](https://github.com/astrobleem/mygithubpage/blob/gh-pages/windows-xt/README.md).
The site links the original PCjs Windows 3.0 demo directly. Windows/DOS/DDK/compiler
media, guest snapshots and diagnostics are not mirrored in this repository.
