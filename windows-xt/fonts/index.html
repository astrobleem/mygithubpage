What you’re seeing

These previews decode the actual XT Pixels R10 .FON files shipped with Windows XT. They use the fonts’ original glyph widths, cell heights and external leading. Zoom is an integer scale with square pixels, not a CRT aspect-ratio simulation or a Windows screenshot.

System and Fixed use early Windows ANSI; OEM uses CP437, including box drawing and control pictures. Characters absent from a font use its original fallback: a box for ANSI, a space for OEM. Euro and emoji are not included. The byte grid shows the exact result of all 256 byte inputs, including substitutions.

XTEOEM and XTCOEM are intentionally byte-identical. XTTSYS is the fixed text-mode System font; this preview does not imply that experimental text-mode display is visually qualified.
