Your pixels, the original font structure

The XT Pixels R10 set comes from Windows XT. XTCSYS includes corrected capital M/W, with 7-pixel ink and 9-pixel advances. I, J, C, E and S each have one extra blank advance pixel to preserve Windows’ measured 8 × 8 dialog base units. All other glyphs and file headers are unchanged. Other XT Pixels files retain their distributed bytes. The CGA packet adds seven compact 5/6-row fonts and the full-coverage 8-row CG6HELV. Six proportional application fonts add XT Tandy I, XT Tandy II and XT Tandy 2K at 8 and 12 rows. They do not replace System, Fixed or Terminal. The six Tandy and three Helv files include the FONTRES container description required by Windows 3 Control Panel; their font resources are unchanged. Previews decode the exact .FON assets at integer zoom with square pixels; they are not CRT simulations or Windows screenshots.

Edits stay in this tab while you switch fonts. Download every edited font you want to keep before closing or refreshing. Nothing is uploaded or installed. Downloads use a new 8.3 filename ending in E; original downloads remain untouched. Undo, redo and both reset buttons operate on the selected font.

Exports change only glyph bitmap bits. Character widths, height, leading, encoding, resource IDs, face names and the Windows FNT/FONTDIR/NE structure are preserved. An unchanged export is byte-identical to its source. These copies retain the original internal font identities: keep backups and test in a separate Windows installation before replacing a system font. Edited copies have not been runtime-qualified in Windows.

ANSI and OEM/CP437 bytes are different. The compact CG1/CG2 fonts draw ASCII; compact OEM also draws box and block characters. Other in-range bytes contain placeholder boxes you can edit. Out-of-range characters use each font’s default byte, shown in the preview warning. CG6HELV retains the full XT Pixels ANSI artwork. The new Tandy faces map CP437 artwork into Windows ANSI, with XT Pixels artwork for ANSI characters missing from CP437. Euro and emoji are not part of these encodings. The atlas displays all 256 byte inputs, including substitutions.

XTEOEM and XTCOEM start byte-identical and can be edited separately. XTTSYS is the fixed text-mode System font; its presence does not qualify experimental text-mode display.

The six T1P/T2P/TKP files adapt VileR’s Oldschool PC Font Pack v2.2: blank side bearings are removed, one spacing pixel is added, and the 12-row versions use a vertical row map. Keep the Tandy CC BY-SA 4.0 notice and XT Pixels MIT notice with these files. Identify any further changes when sharing edited copies. The other 15 fonts retain their MIT notice.
